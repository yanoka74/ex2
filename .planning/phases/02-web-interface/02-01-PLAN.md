       - Return `render_template("index.html", error="파일 크기가 너무 큽니다. (최대 16MB)"), 413`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> Flask /upload | 사용자가 업로드하는 파일 (신뢰할 수 없는 파일 내용) |
| Flask -> filesystem | 임시 파일 저장 및 삭제 |
| Flask -> pandas/openpyxl | 업로드된 엑셀 파일 파싱 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | /upload route | mitigate | File extension check `.endswith(".xlsx")` at route entry + accept=".xlsx" on input element |
| T-02-02 | Denial of Service | /upload route | mitigate | `MAX_CONTENT_LENGTH = 16MB` in Flask config + 413 error handler with Korean message |
| T-02-03 | Tampering | temp file path | mitigate | Use `tempfile.NamedTemporaryFile(suffix=".xlsx", delete=False)` for safe temp path generation, `os.unlink()` in finally block |
| T-02-04 | Information Disclosure | error messages | mitigate | Catch generic Exception and return safe Korean message "파일 처리 중 오류가 발생했습니다", never expose stack traces |
| T-02-05 | Tampering | filename | accept | Using tempfile for storage, original filename is never used for file system operations. secure_filename() not needed since filename is discarded. Low risk for local personal tool. |
| T-02-06 | Spoofing | no auth | accept | Personal local tool, no public access, no authentication needed per REQUIREMENTS.md out-of-scope |
</threat_model>

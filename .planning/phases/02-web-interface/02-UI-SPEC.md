# Phase 2 — UI Design Contract

> Visual and interaction contract for the Flask web interface. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Python/Flask server-rendered) |
| Preset | not applicable |
| Component library | none (pure HTML + inline CSS in Jinja2 template) |
| Icon library | none (no icons needed for this phase) |
| Font | system-default: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans KR", sans-serif` |

**Note:** This is a server-rendered Flask/Jinja2 app. No React, no shadcn, no Tailwind. All styles live in a `<style>` block inside `templates/index.html`. Korean text rendering requires `Noto Sans KR` in the font stack fallback.

---

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps between icon-like elements |
| sm | 8px | Table cell padding (vertical), compact gaps |
| md | 16px | Table cell padding (horizontal), form element gaps, error message padding |
| lg | 24px | Section spacing (between summary and table, between header and content) |
| xl | 32px | Page body padding (left/right) |
| 2xl | 48px | Upload area vertical padding |
| 3xl | 64px | Page top margin to center upload area vertically |

Exceptions: none

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Page background, table background (odd rows) |
| Secondary (30%) | `#F7F8FA` | Table header background, even row stripes (D-05), upload area background |
| Accent (10%) | `#2563EB` (blue-600) | Primary CTA button, page header bar, "새 파일 업로드" button |
| Destructive | `#DC2626` (red-600) | Error message text and left border |

### Accent Reserved For
- Primary upload button background
- "새 파일 업로드" button background (results view)
- Page header/title bar background
- Nothing else. Links and body text remain default dark.

| Token | Value | Usage |
|-------|-------|-------|
| Text primary | `#111827` (gray-900) | Body text, table cell text |

## Layout Contract

### Upload View (initial state, D-01)

```
+------------------------------------------+
| [accent bg] 판매정보 분석기              |  <- header bar, 48px height
+------------------------------------------+
|                                          |
|        엑셀 파일(.xlsx)을 선택하거나      |  <- instruction text, centered
|        이 페이지에 드래그하세요            |
|                                          |
|         [ 파일 선택 ]                     |  <- accent button, centered
|                                          |
+------------------------------------------+
```

- Upload area: centered on page, max-width 480px
- Instruction text: centered, text-secondary color
- File input: hidden native input, styled button trigger
- Full page is drop target (D-03): `document`-level dragover/drop
- Drag-over state: page gets subtle blue overlay (`drag-over` class on body)

### Results View (after upload, D-01)

```
+------------------------------------------+
| [accent bg] 판매정보 분석기              |  <- same header
+------------------------------------------+
| 전체 N건 -> 중복 제거 후 M건, K개 고유코드 |  <- summary (D-06)
+------------------------------------------+
| 마켓명 | 고유코드 | 상품명 | 수량 | 주문일 |  <- table header, secondary bg
|--------|---------|--------|------|--------|
| row 1  | ...     | ...    | 1,234| 2024.. |  <- white bg (odd)
| row 2  | ...     | ...    | 567  | 2024.. |  <- secondary bg (even, D-05)
| ...    |         |        |      |        |
+------------------------------------------+
|         [ 새 파일 업로드 ]                |  <- accent button
+------------------------------------------+
```

- Table: full width within page container (max-width 960px, centered)
- Summary: above table, 24px gap below header (D-06)
- Table header: secondary background, semibold text, left-aligned
- Zebra stripes: odd rows white, even rows secondary (D-05)
- Numbers: right-aligned, comma-formatted (D-07)
- Dates: left-aligned, YYYY-MM-DD format (D-08)
- "새 파일 업로드" button: below table, 24px gap, links to `/` (GET)

### Error State (UPLD-03)

```
+------------------------------------------+
| [accent bg] 판매정보 분석기              |
+------------------------------------------+
|                                          |
| [!] .xlsx 파일만 업로드할 수 있습니다.    |  <- error banner, red left border
|                                          |
|        엑셀 파일(.xlsx)을 선택하거나      |  <- upload area remains visible
|        이 페이지에 드래그하세요            |
|                                          |
|         [ 파일 선택 ]                     |
+------------------------------------------+
```

- Error message: appears above upload area, not replacing it
- Styled as banner: error-background bg, 4px left border in destructive color
- Padding: 16px all sides
- Error text: destructive color, 15px body size

## Interaction States

### File Upload Button

| State | Visual |
|-------|--------|
| Default | Accent background, white text, 8px vertical / 24px horizontal padding, 6px border-radius |
| Hover | Button-hover background (`#1D4ED8`) |
| Active/Processing | Text changes to "처리 중..." (D-04), button disabled, opacity 0.7 |

### Drag-and-Drop (D-03)

| State | Visual |
|-------|--------|
| Idle | No overlay |
| Drag-over | Body gets `drag-over` class: full-page overlay with `rgba(37, 99, 235, 0.08)`, dashed border `2px dashed #2563EB` on upload area (or page edge) |
| Drop | Overlay removed, form auto-submits, button shows "처리 중..." |

### Table Row Hover

| State | Visual |
|-------|--------|
| Default | Alternating white / `#F7F8FA` |
| Hover | `#EFF6FF` (blue-50) background on hovered row |

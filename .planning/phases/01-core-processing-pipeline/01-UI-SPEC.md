## Phase UI Assessment

**This phase has NO user-facing UI surface.**

Phase 1 (Core Processing Pipeline) implements a pure Python data processing module. Its requirements (DATA-01 through DATA-04) cover pandas-based Excel reading, deduplication, and aggregation. The module's interface is programmatic: it accepts a file path or file object and returns a DataFrame plus summary dict.

UI work begins in Phase 2 (Web Interface), which covers file upload, error display, and results table rendering. The UI-SPEC for this project should be created when Phase 2 is reached.

## Copywriting Contract

No user-facing copy in this phase. The module returns structured data, not messages.

The summary dict output (defined in 01-CONTEXT.md) provides raw numbers that Phase 2 will format into user-facing copy:

| Data Point | Source | Phase 2 Will Display As |
|------------|--------|------------------------|
| total_rows | 전체 건수 | "전체 N건" |
| skipped_rows | 건너뛴 건수 | "제외 N건" (invalid quantity or missing key) |
| result_rows | 결과 건수 | "중복 제거 후 M건, K개 고유코드" |
